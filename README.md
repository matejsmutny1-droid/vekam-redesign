# VEKAM — moderný návrh webu

[Otvoriť živý web](https://matejsmutny1-droid.github.io/vekam-redesign/)

Nový vizuálny návrh pre kamenárstvo VEKAM v Žiline – Trnovom. Teplá biela, grafit, hlinený akcent a minimalistická typografia.

## Zachovaný obsah
- Služby, materiály, ónyxové lampy, kontakty a adresa
- Všetkých 168 pôvodných fotografií v 10 kategóriách
- Tri projektové články, dve PDF prílohy a fotodokumentácia

Pôvodný obsah a fotografie pochádzajú z [vekam.sk](https://vekam.sk/). Ide o návrh redizajnu, nie o zmenu pôvodnej stránky. Fotografie a firemné materiály zostávajú majetkom príslušných vlastníkov.

Kontaktný formulár otvorí pripravený e-mail v e-mailovej aplikácii. Cenu ónyxových lámp označujeme ako historický údaj z pôvodnej stránky.

## Lokálny náhľad
```sh
python3 -m http.server 4189
```

Statické HTML, CSS a JavaScript, bez buildu. GitHub Pages publikuje obsah hlavnej vetvy z koreňového adresára.
